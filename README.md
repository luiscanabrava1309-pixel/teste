# 3D Flight Simulator - Real Satellite World

A lightweight, free, browser-based Microsoft Flight Simulator-style flight simulator with real satellite world data and high-detail 3D graphics.

## Features

✈️ **Flight Dynamics**
- Realistic altitude, speed, heading, and climb rate tracking
- Gravity and basic physics simulation
- Fuel consumption system
- Low altitude warnings

🌍 **Real World Exploration**
- 10 real-world locations with accurate coordinates
- Procedural terrain generation
- Satellite imagery-inspired textures
- Dynamic chunk loading system for seamless exploration

🎮 **Flight Controls**
- WASD: Forward/Backward/Strafe movement
- SPACE/C: Climb/Descend
- Q/E: Roll left/right
- Mouse: Look around (press button to lock)
- R: Reset altitude

📊 **Pilot HUD Display**
- Altitude (feet)
- Speed (knots)
- Heading (degrees)
- Pitch and Roll angles
- Climb rate (ft/s)
- Current latitude/longitude
- Fuel percentage
- Engine status
- Real-time warnings

🌤️ **Visual Features**
- Dynamic sky with atmospheric gradient
- Realistic lighting and shadows
- Cloud particles
- Procedurally generated terrain
- Smooth camera movement

## Technology Stack

- **Engine**: Three.js (WebGL 3D graphics)
- **Physics**: Basic gravity and collision detection
- **Rendering**: Optimized chunk-based terrain loading
- **No Dependencies**: Uses only Three.js (loaded from CDN)

## How to Use

1. Open `index.html` in a modern web browser
2. Click "Lock Pointer" to enable mouse look
3. Use WASD to move and SPACE/C to control altitude
4. Click "Random Location" to fly to different real-world locations
5. Monitor the HUD for flight status and warnings

## Tips for Flying

- Maintain altitude above 200 feet to avoid warnings
- Watch your fuel meter - resets when you change location
- Use mouse lock for better flight experience
- Try different locations for varied terrain
- Lower altitude for more detailed ground view
